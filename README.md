# ✂️ Elite Salon Management System

A high-end, full-stack booking platform designed for modern salon operations. This project features an event-driven architecture to handle real-time reservations and customer management.

## 🚀 Tech Stack

### Frontend
- **Framework:** Next.js 16 (App Router)
- **Library:** React 19
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Icons:** Lucide React

### Backend
- **Framework:** Java Spring Boot
- **Database:** MongoDB Atlas
- **Event Streaming:** Apache Kafka
- **Security:** Spring Security & JWT
